# Security policy

Please do not report vulnerabilities in public issues. Send a private report
through the repository owner's security contact with:

- a short description and affected version or commit;
- reproduction steps or a minimal proof of concept;
- impact and any suggested mitigation.

Remove API keys, cookies, QQ identifiers, message contents, database files, and
other private data before sharing logs. Frontier can call external APIs and
operate on platform resources, so reports involving credential exposure,
authorization bypasses, unintended message delivery, or workspace escapes are
especially useful.

There is no guaranteed response-time or supported-version commitment yet. We
will acknowledge actionable reports as soon as practical and coordinate a fix
or mitigation before public disclosure.
