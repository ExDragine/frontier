# 历史归档

本目录保存已结束的设计计划、历史审查记录和过时的实施说明。归档文档保留归档时的内容，作为决策背景、验收范围或问题证据；它们不再按当前代码维护，其中描述的功能可能已经改变、默认关闭或移除。

**当前行为以代码、测试和 `docs/` 下的使用文档为准。** 新增的长期有效说明应放在 `docs/` 根目录或对应插件目录；只有已结束或被取代的计划、审查记录才移入这里。

## 维护约定

- 归档文档只修正路径、失效链接和明显笔误，不改写当时的技术结论。
- 归档前清理指向代码的行号锚点：行号会随代码变化而漂移，历史记录只保留文件级链接。
- 移动或重命名归档文件时，同步更新 `docs/` 中的引用，并运行 `uv run --locked python scripts/check_local_links.py` 确认没有失效链接。
