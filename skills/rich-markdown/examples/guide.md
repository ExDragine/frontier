# 验证 Python HTTP 服务

下面在本机启动一个临时服务，用于确认 Python 和端口可用。请在准备分享的测试目录执行，避免意外展示其他文件。

::steps
1. **启动本机服务**

   ```sh
   python -m http.server 8000 --bind 127.0.0.1
   ```

   终端显示服务正在监听后，保留这个窗口。命令中的地址将服务限制在本机。
2. **验证 HTTP 响应**

   在另一个终端运行：

   ```sh
   curl -I http://127.0.0.1:8000/
   ```

   检查是否收到 HTTP 状态行。无法连接时，先检查第一个终端的错误提示和端口是否一致。
3. **结束测试**

   回到启动服务的终端按 Ctrl+C，然后再次发出请求，确认服务已经停止。
::

## 失败时从哪里查

| 现象 | 下一步检查 |
| --- | --- |
| 找不到 python | 确认解释器安装和命令名称 |
| 端口被占用 | 换用其他未占用端口，同时修改验证地址 |
| 请求无法连接 | 检查服务是否退出、地址与端口是否一致 |

这组步骤保留操作、命令和验证方法，背景说明仍使用正常段落。
