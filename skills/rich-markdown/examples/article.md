# 工具返回之后，为什么模型还要继续处理

工具提供的是查询或执行结果。模型需要把结果与用户的问题对应起来，再判断是否足够回答，或者还需要补充信息。

::section{title="一次查询如何变成回答"}
例如，用户问某个服务是否正常。检查工具返回连接状态和日志，模型要据此说明**哪些部分已确认正常、哪些仍没有证据**。只有拿到工具结果之后，才能完成这个判断。

工具结果也可能只是中间信息：查到订单编号之后，还需要用编号查询订单状态。这时下一步是继续使用工具。
::

::card{title="控制循环的关键" color="blue"}
每次得到新结果，都重新判断它是否足够完成当前请求。足够时回答；不够时补充查询；必要信息只能由用户提供时，向用户询问。
::

::section{title="放到机器人中怎么使用"}
记录本轮的问题、已经获得的结果，以及下一步需要什么信息。为模型和工具设置调用预算，遇到超时或失败时给出可理解的说明。

这里的段落负责解释原因，卡片突出关键判断；无需把整个回答改写成一组标签。
::
