# 分层通俗解释

把 ELI5 理解为“让没有相关背景的普通人也能理解”，不是幼儿角色扮演。它只调整表达层级，不降低事实核验、安全约束和引用标准。

## 选择层级

- **ELI5 / 小白版 / 说人话**：先建立直觉，使用日常词汇；只保留理解结论所需的最短因果链。类比确实有帮助时使用一个，并指出重要的不相似之处。
- **ELI10 / 入门版**：补充必要背景、主要组成部分，以及它们如何相互作用。
- **ELI15 / 详细版**：引入有用术语、具体机制、成立条件、限制和常见例外。
- **Expert / 专家版**：使用准确术语，紧凑说明假设、机制、边界与权衡，不重复基础铺垫。

用户没有指定层级但明确要求通俗解释时，默认使用 ELI5。用户说“再深入一点”或“再简单一点”时，相对上一版移动一级，补充或删减真正的信息，不要只是改变篇幅。

## 组织解释

按当前层级自然覆盖三个要素：为什么会有这个问题或概念、它怎样运作、它带来什么结果。先讲直觉，再引入术语；术语第一次出现时立即用普通话解释。

不要为了简单而删除会改变结论的条件，也不要把类比当作机制本身。遇到错误前提，先温和纠正再解释。对时效性、高风险或需要来源的问题，照常搜索和核验，只把最终表达改成所需层级。

默认只输出用户请求的一个层级并保持适合聊天的长度。只有用户明确要求多层对照、`ELI5 → Expert` 或逐层展开时，才按 ELI5、ELI10、ELI15、Expert 顺序输出多个带短标签的版本。
